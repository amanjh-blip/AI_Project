MovieMind AI is a Flask-based AI Movie Recommendation System that recommends similar movies based on the selected movie. It uses TF-IDF (Term Frequency-Inverse Document Frequency) and Cosine Similarity to analyze movie genres and descriptions and generate the top 6 recommendations with an AI Match percentage. The project is developed using Python, Flask, Scikit-learn, HTML, and CSS and does not require any external API or database.
